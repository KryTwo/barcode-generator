# Barcode Generator (Генератор штрих-кодов)

Пет-проект на Go, генератор штрихкодов с текстом, для печати в формате PDF

## Задача

Получить возможность простой настройки печати штрихкодов в нужном нам формате, ограниченном сферой применения.
Достаточно узкоспециализированный проект, который, тем не менее, может подойти для использования в иных целях.

## Пронцип работы

На входе csv документ, с двумя нужными столбцами: код и текст (накладываемый на ШК для его визуальной идентификации)
На выходе готовый pdf с настраиваемым выводом штрихкодов, в нужных размерах (в мм)

## Технологии

Попытка написать самостоятельный софт, в идеале Portable приложение, запускаемое на любой платформе.
* **fyne** - GUI 
* **gofpdf** - работа с PDF

## Процесс разработки

На данном этапе уже обладает большей частью задуманного функционала и успешно используется в коммерческих целях.
Шлифуется и полируется.


## Известные проблемы\недоработки (еще не решенные\решаемые)

Проблема запуска на неподготовленной ОС, без компилятора CGO
Нет функционального бинарника
Нет разделения по платформам
Нет разделения по разрядности системы
